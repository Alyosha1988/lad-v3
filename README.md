# Лад · Рифф (v3)

От захвата на грифе / клавишах — к аккордовому ходу и идеям развития.

## База постановок

- 12 корней × 30 качеств
- Гитара: open + E/A/D/C/G-формы (+ октавы)
- Фортепиано: тесное положение, инверсии, drop-2

Смотри `voicings.js` → `voicingStats()`.

## Поток

1. **Гриф** — зажим → распознавание → все постановки → «В ход»
2. **Ход** — порядок, дублирование постановок
3. **Развитие** — продолжения, замены, другие хваты

Лад+: только сохранение на устройстве.

## Локально

Открой `index.html` или любой static server.
